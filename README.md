# 🏢 ERP Fullstack System

Sistema completo de gestión empresarial desarrollado como simulación de entorno real, integrando backend, frontend y módulo analítico.

---

## 🚀 Componentes del sistema

### 🔹 ERP Backend (Laravel)
Sistema principal para gestión de ventas, productos y usuarios.

👉 https://github.com/jcyontonel/proyectoERP-Laravel

---

### 🔹 Módulo Analítico
Procesamiento de datos y generación de reportes.

👉 https://github.com/jcyontonel/analitica_erp

---

## 🧠 Arquitectura

El sistema sigue un flujo tipo:

1. Registro de datos en el ERP
2. Almacenamiento en base de datos
3. Procesamiento de datos (ETL)
4. Generación de información analítica

## 🎯 Objetivo del proyecto

Diseñar e implementar un sistema integral de gestión empresarial (ERP) con módulo analítico, orientado a centralizar la operación de negocio y facilitar la toma de decisiones mediante el procesamiento y análisis de datos.

El proyecto simula un entorno real, integrando procesos transaccionales, almacenamiento de datos y flujos de transformación (ETL), con el objetivo de demostrar capacidades en desarrollo fullstack, modelado de datos y automatización de procesos. 

## 🧩 Alcance
- Gestión de operaciones (ERP)
- Procesamiento de datos (ETL)
- Generación de información analítica
- Automatización de tareas
